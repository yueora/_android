# YUEORA Music — نسخهٔ اندروید

این پوشه نقطهٔ شروع تبدیل فایل اصلی سایت YUEORA به اپلیکیشن Android است.

## مشخصات ثابت پروژه
- نام نمایشی: **YUEORA Music**
- شناسهٔ بسته: `com.yueora.music`
- فناوری: Capacitor 8.6.2
- فایل وب اصلی: `www/index.html` (کپی فایل اصلی تحویل‌داده‌شده، نه نسخهٔ تم آبی موقت)
- بک‌اند: همان Supabase فعلی YUEORA

## ساخت APK بدون نصب Android Studio روی گوشی
این پروژه یک GitHub Actions workflow دارد تا ساخت APK در فضای ابری GitHub انجام شود.

1. یک مخزن GitHub برای اپ بساز.
2. محتویات همین پوشه را در ریشهٔ مخزن بارگذاری کن.
3. از بخش **Actions**، گردش‌کار **Build YUEORA Music APK** را باز کن.
4. روی **Run workflow** بزن.
5. پس از پایان موفق، از صفحهٔ همان اجرا، بخش **Artifacts**، فایل `YUEORA-Music-debug-apk` را دریافت کن.
6. فایل APK را روی گوشی نصب کن. برای نصب، Android ممکن است اجازهٔ نصب از همان مرورگر/فایل‌منیجر را بخواهد.

با هر push به شاخهٔ `main` نیز workflow اجرا می‌شود.

## اجرای محلی (در کامپیوتر)
نیازمندی‌ها: Node.js 24+، Android Studio و Android SDK. سپس:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

## وضعیت این نسخه
- پوستهٔ اولیهٔ اپ Capacitor آماده شده است.
- فایل اصلی سایت داخل اپ قرار گرفته و منطق و ظاهر اصلی آن عمداً بازنویسی نشده است.
- پل ارتباطی اولیه برای نوار وضعیت، صفحهٔ شروع و دکمهٔ Back اندروید اضافه شده است.
- وب‌سایت اصلی و پنل مدیریت مستقل، با این پروژه جایگزین یا ادغام نشده‌اند.
- APK هنوز در این محیط ساخته یا روی گوشی نصب و آزمایش نشده است.

## کارهای بعدی پیش از انتشار
1. تست واقعی ورود، Supabase، پخش و ناوبری در WebView اندروید.
2. پیاده‌سازی پخش پس‌زمینه با سرویس/اعلان رسانه‌ای اندروید؛ صرفاً بازماندن audio در WebView را پخش پس‌زمینهٔ تضمین‌شده حساب نمی‌کنیم.
3. دانلود امن فایل آهنگ‌ها در حافظهٔ خصوصی برنامه و پخش آفلاین منتخب‌ها.
4. همگام‌سازی کتابخانهٔ کاربر و پیاده‌سازی مدیریت مستقل دانلودهای آفلاین.
5. آیکون، اسپلش نهایی، امضای نسخهٔ انتشار و تست روی چند اندازهٔ صفحه.

## سیاست قطعی علاقه‌مندی و دانلود آفلاین
- حذف یک آهنگ از علاقه‌مندی‌ها فقط آن را از فهرست علاقه‌مندی‌ها حذف می‌کند.
- فایل صوتی دانلودشده باید در حافظهٔ خصوصی اپ باقی بماند و از بخش «دانلودها / آفلاین» همچنان قابل پخش باشد.
- حذف فایل دانلودی باید یک عملیات مستقل و جدا از حذف علاقه‌مندی باشد.
- اگر آهنگی از علاقه‌مندی‌ها حذف شد، وضعیت دانلود آن نباید تغییر کند.

## نکتهٔ آفلاین
در فایل فعلی، علاقه‌مندی‌ها و پلی‌لیست‌ها با `localStorage` نگهداری می‌شوند. این به‌تنهایی دانلود فایل صوتی یا پخش آفلاین ایجاد نمی‌کند. قابلیت آفلاین باید جداگانه به حافظهٔ داخلی اپ متصل شود و فهرست دانلودها مستقل از علاقه‌مندی‌ها ذخیره شود.
